🚗 Consulta FIPE - Projeto de Estudo

Este projeto é uma aplicação web que permite consultar valores de veículos utilizando a API pública da Tabela FIPE, trazendo informações atualizadas de forma dinâmica diretamente na interface.

📌 Sobre o projeto

O Consulta FIPE foi desenvolvido como parte dos meus estudos em JavaScript, consumo de APIs e manipulação do DOM.

A aplicação permite ao usuário selecionar:

Tipo de veículo (carro, moto ou caminhão)
Marca
Modelo
Ano

E então visualizar o valor atualizado do veículo com base na Tabela FIPE.

🚀 Tecnologias utilizadas
HTML5
CSS3
JavaScript (ES6+)
Fetch API
API pública FIPE
🔗 API utilizada

Este projeto consome dados da API pública:

https://parallelum.com.br/fipe/api/v1/
🎯 Funcionalidades
Seleção dinâmica de marcas, modelos e anos
Consulta de valores em tempo real
Atualização automática dos campos via JavaScript
Interface simples e responsiva
Validação básica de fluxo de dados
